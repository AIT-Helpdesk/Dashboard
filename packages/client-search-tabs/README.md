# @dashboard/client-search-tabs

Dashboard page: "Client Search" in the sidebar -- a tabbed bundle of three already-independent client-lookup pages, shown as tabs on one page instead of three separate sidebar entries. Generated by Tab Page Builder. The actual tab-strip mechanism (drag-to-reorder, admin-only add/remove/reorder, the shared permanent-tabs/removed-default-tabs/tab-order settings) lives in `@dashboard/shell`'s `tab-page-client.js`/`tab-page-server.js`, reused by every tabbed page on this dashboard -- see those files for the full implementation, not repeated here.

- `client.js` - calls `createTabbedPageMount()` (`@dashboard/shell/public/tab-page-client.js`) with this page's own `id`/`label`/`apiBase` and its three default tabs.
- `server.js` - re-exports `createTabPageRouter(__dirname)` (`@dashboard/shell/tab-page-server.js`), the generic settings backend for this page's own tab list/order.

## Default tabs

- **Client Contacts** (`client-contacts`) -- pick which contacts to show (primary, main billing, both, or all active), optionally filtered by Client/Contracts/Classification wildcards; includes CSV export and a "Resolve Duplicates for Mailing List" tool.
- **Clients by Classification** (`classification-summary`) -- active clients grouped by one of five dimensions (Classification, Market Segment, Referrer, Contract Name, Service), one tab each, with wildcard search and collapsible groups.
- **Find Passwords** (`find-passwords`) -- search IT Glue password entries by name; metadata only (client, username, category, OTP flag, last-changed date), never the password value itself or its notes field.

See each page's own README (`packages/client-contacts/README.md`, `packages/classification-summary/README.md`, `packages/find-passwords/README.md`) for the full behaviour of each tab -- this page doesn't change how any of them work, it just mounts their existing `client.js` module in a tab instead of a standalone sidebar entry.
